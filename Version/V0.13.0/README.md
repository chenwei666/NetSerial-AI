## 一句话发起任务，高风险才确认

1. 连接 USB Console、SSH 或 Telnet，完成登录并停在正常 CLI 提示符；从这台设备的终端打开 AI，再进入“AI 自动执行”。
2. 描述明确目标并开始。任务绑定当前连接令牌，只使用你选中的 AI 厂商/模型，不自动切换备用厂商。缺参数时追问，不接受在普通聊天中输入密码。
3. 已识别设备、完成必要现状读取后，精确白名单查询和任务范围内的有限常规配置可自动执行；目前常规配置主要是指定 VLAN 与受限描述，并非所有 R2 命令都自动放行。
4. 高风险或未知风险命令暂停，要求输入完整目标名称确认；受保护设备还必须满足匹配的变更任务和维护窗口。设备回显、模型和记忆都不能授予执行权限。

每次最多 32 步、10 分钟；逐步等待回显。错误、交互/分页、超时、断线或目标变化停止，无自动重试。离开页面或点击停止不会继续下发，也不会自动恢复、回退或保存配置；已经发送的命令可能已生效。

### Web 账号与 HTTPS 的本地安全流程

`WEB_ACCESS` 将用户名和协议选择交给本地厂商模板：H3C Comware 5/7、Huawei VRP、Cisco IOS/IOS XE、Ruijie RGOS。未证明支持的设备/版本不能视为已兼容。密码在专用本地安全输入框填写，以 `char[]` 交给本地执行器，不进入 AI 请求、聊天或记忆；模板整体需一次高风险确认，可能创建/覆盖账号及管理权限。

敏感命令后，终端与 AI 回显持续隐藏，必须重新连接再读取结果，以避免延迟口令回显泄漏。CLI 提示符返回仅说明命令流程结束，**不证明网页可访问或账号登录成功**。不会自动保存或回退。输入数组会清零，但模板/传输层仍可能产生 JVM String 和系统副本，不承诺内存彻底擦除；请使用可信输入法，优先 HTTPS。

自动任务沿用普通聊天的“使用已确认记忆”设置，每次最多 5 条；不自动写入新记忆。长期记忆仍需用户显式确认保存，不构成永久授权。

## 保留的 V0.12.0 工具箱基础

- 工具按用途分类，可搜索；选中后只展示相关参数。手机与平板自适应，中英文、深浅色沿用应用设置。
- Ping 显示真实回包 RTT、丢包统计和趋势，不再把进程总耗时冒充延迟；无回包不填成 0 ms。
- 结果区优先展示结论、关键数值和明细，原始输出可折叠。失败、部分完成、系统不支持和取消分别呈现，不把错误文本当作成功。
- 任务可停止，资源有超时和输出上限。报告脱敏后先预览，再复制、分享或带入 AI 草稿；不会自动调用 AI。

## 16 个常用工具入口

| 用途 | 工具与结果 |
| --- | --- |
| 基础排障 | 一键基础体检：组合单目标检测；Ping：逐包与统计；TCP：指定端口连接状态与耗时 |
| 路径与地址 | 路由追踪：免 Root TTL 探测；MTU：IPv4 不分片探测；地址摘要：解析结果与地址属性 |
| 域名与网站 | DNS：A、AAAA、CNAME、MX、TXT、NS、PTR；HTTP/HTTPS：HEAD 状态与响应头耗时；TLS：信任链、域名、有效期及协商参数 |
| 当前网络与局域网 | 本机网络信息；受限局域网发现；Wake-on-LAN 唤醒报文 |
| 离线辅助 | IPv4/IPv6 CIDR 与掩码计算；MAC/OUI 查询；常用端口速查；IP/MAC 等文本标识提取 |

### 用之前要知道

- **免 Root 不等于每部手机都支持所有探测。** 路由追踪依赖系统 Ping/TTL 能力及中间设备回包；星号表示未知，权限限制明确提示不支持。MTU 只做 IPv4 DF 探测：超时不能证明报文过大，1500 字节成功仅证明至少可通过该大小。
- **局域网发现需要明确确认。** 仅接受 RFC1918 私网 `/26`–`/32`，最多 64 个地址、4 个指定 TCP 端口，40 秒预算。它不是完整设备清单：未响应不代表离线，不扫描公网。只用于自己拥有或获授权的网络。
- **WOL 需要明确确认。** 单次向指定 IPv4 地址的 UDP 9 端口发送 102 字节报文；“已发送”不代表设备已开机。
- DNS 使用当前系统 DNS 或你填写的 `TYPE @服务器IP`，不偷偷切换公共 DNS。系统未提供 DNS 地址时，只有 A/AAAA 可回退系统解析；不验证 DNSSEC。
- HTTP 只发 HEAD，不下载正文、不跟随跳转、不发送账号或 Cookie；405 表示服务器不支持 HEAD。HTTPS/TLS 不绕过证书或域名校验；TLS 工具不做全部协议或吊销状态扫描。
- OUI 依赖内置数据，未知厂商明确显示未知。网络信息受 Android、VPN 和厂商限制，不声称能读取受保护的 Wi-Fi 标识。

## 构建与安装

运行 `scripts/build.ps1` 执行单元测试、Lint 与 Debug 构建。工具链为 `C:/tmp/NetSerial-tools`，隔离镜像为 `C:/tmp/NetSerial-v0130-build`。

当前配置 versionName `0.13.0`、versionCode `15`；Debug 包名 `com.chenwei666.netserial.preview013`、版本 `0.13.0-preview`，与正式版共存且不自动导入其数据。正式 applicationId 为 `com.chenwei666.netserial`，生产包沿用原证书，已完成 V0.12.0 → V0.13.0 覆盖升级及冷启动验证。生产 SHA-256 和独立预览 SHA-256 见 [校验文件](docs/SHA256SUMS.txt)；公开发布状态以仓库根记录及 Release 为准。后续升级必须保留原生产证书。

最低 Android 5.0；加密长期记忆需要 Android 6.0+。新增普通权限 `ACCESS_NETWORK_STATE` 用于读取当前网络/DNS，不申请 Root。实际测试数据与未验证范围以 [测试报告](docs/TEST_REPORT.md) 为准，不能把本地回环/模拟器测试当作所有手机、真实交换机或公网服务验收。
