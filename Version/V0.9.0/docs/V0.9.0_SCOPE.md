# V0.9.0 范围与验收 / Scope and Acceptance

发布日期目标：2026-08-25
开发人员：chenwei666

## 目标

V0.9.0 定位为“现场智能运维闭环版”。本版本在保留 V0.8.0 全部能力的基础上，把 AI 命令提案扩展为可持久化的应用内多轮对话，并补齐故障采集、运行手册、配置漂移、安全巡检和变更检查清单。

## 交付范围

- versionCode 10、versionName 0.9.0，最低 API 21、目标 API 36。
- 应用内 AI 多轮对话：新建会话、历史消息、停止请求、失败重试、复制、分享、清除、设备上下文、终端上下文和本地记忆。
- 复用全部已配置 AI 厂商与动态模型，支持 OpenAI-compatible、Anthropic 原生协议和 HTTPS Ollama。
- AI 对话内容在发送前执行终端控制符清理、敏感字段脱敏、提示注入隔离和长度限制。
- AI 回复中的命令仅作为草稿展示；经确定性规则重新评估风险后，才允许人工装载到终端输入区，R4 命令保持阻断。
- 对话历史在 Android 6.0 及以上通过 Android Keystore 加密保存；旧系统仅保留当前内存会话。
- 一键故障采集计划、配置漂移判定、安全基线巡检、结构化运行手册和变更闭环检查清单。
- 中文、英文资源以及 README、CHANGELOG、架构、安全、测试和发布文档同步更新。

## 安全边界

- AI 不自动执行或后台发送交换机命令。
- 对话历史、终端输出和设备记忆不会写入日志或导出，除非用户主动分享经过脱敏的文本。
- 不实施无限制网段扫描、后台资产发现或未经批准的协议写配置。
- NETCONF、RESTCONF、gNMI、Syslog/SNMP Trap 等需要真实设备和长期后台运行的能力不冒充完成；本版本保留后续适配接口和实施路线。

## 验收条件

- 多轮消息顺序、上下文裁剪、厂商请求编码、响应解析、故障转移和取消均有自动化测试。
- 会话存储具备数量、消息数、单条长度和总序列化大小限制，损坏数据失败关闭。
- 故障采集、配置漂移、安全巡检和运行手册覆盖华三、华为、Cisco、锐捷及通用回退。
- 全量 JVM 测试、Debug/Release Lint、Debug/Release 构建、签名、ZIP 对齐和 APK 元数据检查通过后方可正式发布。
- 真实 Android、USB、交换机和付费 AI 账号仍需在授权环境执行现场验收。

## English summary

V0.9.0 turns the existing command-draft copilot into an in-app, multi-turn network operations assistant with encrypted local history, cancellation, retry, safe command extraction, context redaction, and provider failover. It also adds incident collection plans, configuration drift assessment, security posture checks, guided runbooks, and a change-closure checklist. AI remains draft-only and all device actions require explicit human review.
