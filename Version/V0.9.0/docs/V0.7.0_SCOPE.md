# V0.7.0 范围与验收 / Scope and Acceptance

发布日期：2026-08-24
开发人员：chenwei666

## 已包含

- 五区响应式导航、全局搜索、收藏和最近使用。
- AI 多厂商失败转移，保留任意 OpenAI-compatible 厂商接入和本地授权记忆。
- 健康分析、端口定位、配置备份、LLDP/CDP 解析和 SNMPv3 只读采集计划。
- Android Keystore 设备凭据别名、限时 HTTP/TFTP 共享和签名运行手册验证。
- 受控批次安全内核、Android 16 返回手势兼容和 Android 5–16 签名验证兼容。

## 安全验收

- 终端菜单不再包含全局设置/连接等重复入口。
- AI 失败记录不包含原始异常、密钥或请求正文。
- 配置备份先清洗 ANSI、脱敏、规范化，再计算 SHA-256。
- 临时共享仅允许私有/回环地址、随机令牌、GET/只读模式、有限时长与次数。
- 运行手册必须通过 RSA/SHA-256 签名并通过明文凭据检测，私钥永不进入应用。
- 受控批次必须具备预检、变更、验证、回退和逐目标审批；默认无生产连接适配器。

## 明确不冒充已完成的外部验收

- 未在本自动化环境连接实体 Android、USB OTG、交换机、SNMPv3 Agent 或真实 AI 付费账号。
- SNMPv3 当前是受限查询计划器，不主动扫描；拓扑由用户提供的 LLDP/CDP 文本解析。
- Debug APK 仅用于验证，不等同于使用历史生产证书签名的正式 Release APK。
