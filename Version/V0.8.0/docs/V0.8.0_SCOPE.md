# V0.8.0 范围与验收 / Scope and Acceptance

发布日期目标：2026-08-25  
开发人员：chenwei666

## 用户需求

1. 继续优化界面，使首页、菜单、AI 设置和网络工具箱符合现代移动应用的视觉与交互习惯。
2. 补齐 AI 厂商，至少包含智谱；厂商模型应从各自上游 API 动态获取。
3. 网络工具箱应更直观，常用诊断可直接到达，结果便于复制和分享。
4. 在不削弱现有功能和安全边界的前提下补充适合网络运维现场的功能。

## 交付范围

- versionCode 9、versionName 0.8.0，最低 API 21、目标 API 36。
- 18 类 AI 接入入口，保留自定义 OpenAI-compatible 与 HTTPS Ollama。
- OpenAI/Anthropic 兼容 data[].id 以及 Ollama models[].name 模型目录解析。
- 上游模型同步具备 HTTPS、认证头隔离、响应大小限制、超时、取消、缓存和手工回退。
- 首页、功能搜索和功能中心使用统一 Material 3 任务卡片。
- 网络工具箱使用任务分区，并支持单目标最多 16 端口、地址摘要、结果复制/分享。
- 中英文资源、README、架构、安全、测试、发布和 CHANGELOG 同步更新。

## 非范围

- 不把 AI 结果自动发送到交换机。
- 不在没有用户 API Key 的情况下代理或中转厂商请求。
- 不进行网段端口扫描、后台资产扫描或主动 SNMP 发现。
- 不提交 APK、API Key、Token、生产签名或真实设备配置到 Git。

## 验收条件

- 新旧 ProviderProfile 数据可继续读取，原有 AI 配置无需迁移数据库。
- 所有预置厂商均能生成合法 HTTPS 对话和模型目录地址；不支持目录接口时保留手工模型输入。
- API Key 不进入 SharedPreferences 模型缓存、日志、界面回显或版本文档。
- 端口列表去重、范围展开且上限为 16，非法端口和反向范围被拒绝。
- 全量 JVM 单元测试、Debug/Release Lint、Debug/Release 构建、签名、ZIP 对齐和 APK 元数据检查通过后方可正式发布。
- 真实 Android、USB、交换机及付费 AI 账号仍需在授权环境执行现场验收。

## English summary

V0.8.0 modernizes navigation and high-use screens, expands AI provider coverage, retrieves model catalogs from provider APIs with safe caching and manual fallback, and redesigns the network toolbox around direct field tasks. AI remains draft-only, model sync remains user-initiated, credentials never enter the model cache, and TCP checks remain bounded to one target and sixteen explicit ports.
