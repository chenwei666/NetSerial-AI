# NetSerial AI V0.4.0 交付范围

版本：V0.4.0  
日期：2026-08-21  
开发人员：chenwei666

## 目标

在 V0.3.1 的 USB Console、SSH、Telnet、命令补全、命令库与多厂商 AI 草稿能力之上，补齐网络运维现场从“确认目标、变更前检查、执行、验证到留证”的闭环。所有高风险动作仍由工程师审核和确认，AI 不得绕过本地安全门禁。

## 必须交付

1. 变更任务：登记工单、站点、设备、工程师、维护窗口、目标、前置检查、验证与回滚，记录脱敏时间线，导出 Markdown 和 PDF。
2. 防错设备：设备环境、受保护标记、管理地址、常驻彩色目标条；受保护目标的 R3/R4 命令必须匹配有效变更任务和维护窗口。
3. 配置对比：变更前后配置规范化、SHA-256、逐行差异、厂商感知的回滚草稿和 Markdown 导出。
4. 网络工具：IPv4/IPv6 CIDR、DNS、Ping、Traceroute、TCP 端口、路径 MTU、MAC/OUI、常用端口参考、IP/MAC/接口标识提取。
5. SSH 增强：密码/键盘交互、会话级私钥、跳板机、Keepalive、SFTP 上传下载；严格主机密钥校验，私钥和口令不得持久化。
6. AI 运维计划：强制呈现预检查、变更、验证、回滚阶段；引入变更任务上下文但按不可信文本处理；检测提示注入；输出仍为草稿。
7. 安全补强：多行粘贴逐行分级、常见网络设备凭据脱敏、SFTP 上传按高风险动作确认。
8. 设置与本地化：中英文切换、SSH Keepalive、网络探测超时，新增界面和提示必须双语。
9. 质量与发布：单元测试、Android Lint、Debug/Release 构建、签名与哈希校验、完整中英文说明、独立 `Version/V0.4.0` 归档。

## 明确边界

- 不保存 SSH 私钥、SSH/Telnet 口令或跳板机口令。
- 不自动执行 AI 输出，不允许 AI 生成的 R4 命令进入执行链。
- 内置 OUI 仅为离线小型参考表，未知结果不代表设备异常。
- Ping、Traceroute 和路径 MTU 受 Android 系统工具、网络 ACL 与 ICMP 策略影响。
- 真机 USB、真实交换机、真实 AI 账户与真实跳板链路需在授权测试环境完成外部验收。
