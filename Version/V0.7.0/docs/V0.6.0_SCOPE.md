Developer: chenwei666  
Date: 2026-08-24

## Included

- Offline vendor fingerprinting for H3C Comware, Huawei VRP, Cisco IOS, and Ruijie RGOS.
- Vendor-specific Web access drafts with HTTPS by default and ephemeral credentials.
- GitHub Latest update checks with semantic-version comparison and restricted release URLs.
- AI diagnosis prefill, explicit memory opt-in, and four-phase plan validation.
- Read-only operations playbooks, CLI neighbor discovery, heuristic compliance triage, and canary-first batch plans.
- Non-sensitive multi-session profiles and private redacted configuration snapshots.
- Completion ranking improvements, custom command packs, and USB XMODEM-128 send.
- Bilingual Simplified Chinese/English UI and documentation.

## Safety acceptance

- No planned batch has direct connection or execution capability.
- Web passwords are not persisted, copied to preview, exported, or recorded in change evidence.
- Update URLs must use HTTPS and the GitHub domain.
- R3/R4 command, target, protected-device, and maintenance-window gates remain authoritative.
- XMODEM requires a connected USB terminal, R3 authorization, file-size limit, SHA-256 preview, receiver negotiation, timeout, and retry limits.
- Imported terminal/configuration content is bounded, ANSI-cleaned, and redacted before AI, snapshot, compliance, or export use.

## External acceptance still required

- Real Android devices from the supported API range and common USB OTG chipsets.
- Representative H3C, Huawei, Cisco, and Ruijie models/releases.
- Real SSH/Telnet/SFTP, jump-host, AI-provider, GitHub update, and XMODEM receiver paths.
- Accessibility, large font, landscape, slow network, interruption, and long-session checks.
