# NetSerial AI V0.5.0 交付范围

版本：V0.5.0  
日期：2026-08-21

## 已交付

1. 统一 Material 3 DayNight 外观体系。
2. 跟随系统、浅色、深色三种显示模式。
3. 海洋蓝、翡翠绿、科技紫、日落橙四套主题。
4. 全 Activity 统一应用语言、主题、显示模式和防休眠设置。
5. 首页运维工作台、设备档案摘要、活动变更摘要和六个快捷入口。
6. 现代化 USB 设备卡片与双语设备状态。
7. 命令收藏、最近使用、范围筛选和清空记录。
8. 连接与操作期间屏幕常亮开关。
9. 深浅模式终端颜色、中英文 README/资源、单元测试、Lint、签名 Release 和独立版本归档。

## 保持不变

- USB、SSH、Telnet、SFTP 连接协议和生命周期。
- AI 厂商兼容范围、Keystore 凭据保护和草稿式执行边界。
- R3/R4 命令确认、生产设备变更门禁和目标防错。
- 配置 Diff、变更证据、网络诊断工具和设备记忆。
- applicationId、minSdk 21、targetSdk 36 和生产签名链。

## 数据与隐私

- 不涉及数据库。
- 新增的命令历史只保存内置目录命令标识，最多 30 条最近使用，不监听或记录终端输入。
- 不新增账号、密码、API Key、Token、私钥或设备配置日志。

## 外部验收

- 真实 Android 5.0+、不同分辨率、字体缩放、系统深浅切换和厂商省电策略。
- USB OTG、SSH/Telnet/SFTP、真实交换机和自有 AI 账号。
- V0.4.0 到 V0.5.0 的同签名覆盖安装与用户数据保留。
