# V0.1.0 安全说明

## 已实施

- Android 自动备份关闭。
- 明文 HTTP 默认关闭。
- 仓库忽略 `.env`、密钥库、本地 SDK、构建缓存和 APK/AAB。
- AI 供应商草案必须通过本地 `ExecutionGuard`。
- AI 风险等级不能降低确定性规则给出的风险。
- R4 命令需要强确认且永不允许自动执行。
- API Key、Token、密码、私钥和 SNMP 团体字不属于 AI 记忆数据。

## 后续接入真实 AI 前的门禁

1. 个人 BYOK 使用 Android Keystore 保护的 AES-GCM 密文，不记录明文。
2. 企业部署优先使用 AI Gateway 短期令牌，供应商长期密钥只在服务器保存。
3. 每个供应商适配器必须限制 HTTPS、请求超时、响应大小、模型能力和费用预算。
4. 发送前展示并脱敏终端上下文；设备输出和知识库内容都按不可信输入处理。
5. 崩溃日志、备份、测试夹具和导出文件必须通过敏感信息扫描。

V0.1.0 没有真实 AI 网络调用，也没有任何密钥存储入口。
